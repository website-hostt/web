FAANOMATE WEBSITE / PORTFOLIO EDITION

OPEN LOCALLY
Double click index.html after extracting the ZIP. Keep all companion files
and the assets folder together. No installation or local server is needed.
The separate FAANOMATE-Website-v3.html file is a self contained alternative.

WHAT IS INCLUDED
White and blue brand lockup and Create / Build / Automate word cycle.
Pointer driven WebGL water ripples, parallax, scroll reveals and a thinner
continuous service ticker. Digital marketing, Development and Design menus
open 20 concise service descriptions with relevant tools and enquiry links.

26 PORTFOLIO ENTRIES
1 client website: ITFume, with a live site link.
1 UI/UX client project: Grel, with all eight study sections, seven boards,
an interactive prototype link and the original 16 page PDF link.
8 motion projects: Cartroids, WinAds, EraOfEcom, CareToday, Green Screen,
Jungle, KipBox and RegenCore. These play through Vimeo and need internet.
15 graphic designs: original campaigns and editorial artwork.
1 Tableau story: Hotel Booking Analysis, with a themed title thumbnail and
a direct link to the interactive story supplied by the owner.

SHOWREEL
60 seconds, 1920 x 1080, 30 fps, H.264 video with AAC audio.
New five second intro and 5.2 second outro using the approved split logo,
the existing reveal choreography, the brand palette, animated rings and
Create / Build / Automate typography. The original work montage uses the
personal reel from 3.000 to 52.800 seconds. Original music is retained with
opening and closing fades. The old personal intro and contact ending are
removed. The old company logo is not used. The original seven second logo
film loops in the footer and respects the motion pause setting.

EDITING
index.html: site layout, copy, navigation and contact.
content.js: project catalogue, service descriptions and tool groups.
styles.css: appearance, responsive rules and CSS motion.
app.js: navigation, galleries, forms, video and interaction logic.
water.js: interactive WebGL ripple surface.
assets/: all local images, icons, logos and video.

ACCESSIBILITY
Keyboard friendly dropdowns and dialogs, visible focus states, native form
validation, motion pause control, responsive layouts and system reduced
motion support. WebGL gracefully skips the water layer when unavailable.

VALIDATION
Direct file opening in Microsoft Edge, desktop and mobile layouts,
portfolio filters, gallery pagination, service menus, tool groups, enquiry
flow, video metadata and playback, local image references and text review.
See ASSET-NOTES.txt for source provenance and content limitations.

REFINEMENT EDITION
White FM monogram in the header. The hero uses the original logo reveal
choreography with white and blue paths, a three second fully formed hold,
and a short fade before repeating. Reduced motion shows a static logo.

Service section order: Design, Development, Digital marketing. Each has
a relevant icon. Process cards stay fully visible and are selectable.
